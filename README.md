# INTRO

This web site allows users to mix paints, calculate the output of these colours (shade) and save these recipes or shades for painting and stuff u like to do.


## About This Web site

The Recipe maker helps artists and painters and create their own recipes or shades by entering paint colours in **HEX** or **RGB** format along with the number of drops used. The site then automatically calculates the final mixed colour and then the user can save, search, edit, and favourite their paint recipes.


## Its features

- You can mix paints
- This website will caclculate the output colour or the shade on its own.
- You can write the colours in rgb or hex code.
- You can also sace recipes using local storageee :D
- Automatically saves ur drafts
- Made a mistake? Feel free to edit the recipes.
- Don't like the recipe? delete them, eazz.
- Oh also, favourite recipes for quick access.
- Lost ur recipe?? Don't worry search it up on the search recipes.
- It can also sort out recipies for u 
- I also added pagination hehehe
- Copy HEX and RGB values of ur output colorrr
- Name your output color as u wish
- Oh also there is a cat in home and recipe page hover and click it to find out what happens hehehe

## 🚀 How to Use

1. Enter the number of paints.
2. Click **Generate**.
3. Enter each paint's HEX or RGB colour.
4. Enter the number of drops.
5. Click **Mix Colours**.
6. Enter a recipe name.
7. Enter a shade name.
8. Save the recipe.
9. View and manage recipes from the History page.
